# ADR (결정 기록)

PR 하나에 ADR 하나를 쓴다. 그 PR을 구현하며 직접 고른 것과 이유를 남긴다. 프로젝트 전체에 걸친 결정은 `docs/decision/decisions.md`, 단계 설계는 `docs/decision/specs/`에 있다.

- 파일: `docs/adr/NNNN-<주제>.md`. `NNNN`은 0001부터 차례로 붙인다.
- PR 브랜치 안에 `Docs:` 커밋으로 넣고, PR 본문의 "검토 포인트"에 경로를 적는다.
- 계획이 이미 정한 것은 "계획대로"로 짧게 적고, 계획에 없던 선택과 `.chat/`의 `ask`/`answer`로 정한 것을 자세히 적는다.

## 템플릿

```markdown
# ADR NNNN: <제목>

- 상태: 채택
- 날짜: YYYY-MM-DD
- 이슈: #<번호> 태스크 <번호>
- 계획: `docs/decision/plans/<파일>.md`

## 맥락

<이 PR이 푸는 문제, 계획이 정하지 않고 남긴 것>

## 결정

| 결정 | 이유 | 버린 대안 |
|---|---|---|
| | | |

## 결과

<이 결정으로 생기는 제약, 다음 태스크가 알아야 할 것>
```
